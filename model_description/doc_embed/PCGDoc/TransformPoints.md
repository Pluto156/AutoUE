# PCGTransformPointsSettings 
## Documentation

Official Description:  
Changes the points’ transforms (either in place or to an attribute with **Apply to Attribute**) using basic random rules.  
Each component of the transform (translation, rotation, scale) can be set to **Absolute** instead of relative to allow for more control.

Detailed Explanation:  
The **Transform Points** node is a core PCG (Procedural Content Generation) utility that modifies point data through transformations — including translation, rotation, and scaling — based on configurable parameters.  
It enables procedural variation, alignment correction, or randomized placement adjustments for point-based data (such as points generated by samplers or scatterers).  

By default, transformations are applied relative to the point’s existing transform. When **Absolute** options are enabled, the corresponding transform component (offset, rotation, or scale) is replaced rather than modified.  
This gives designers fine-grained control over the final spatial arrangement of generated points.  

The node can also store transformed results in a separate attribute if **bApplyToAttribute** is enabled, preserving the original point data.  
When **Recompute Seed** is checked, the node updates each point’s procedural seed according to its new position, ensuring that downstream nodes (like random-based scatterers) produce deterministic yet spatially coherent results.

**Example:**  
Using a Transform Points node with **Absolute Rotation** and setting **Rotation Z = 0** ensures that all sampled points align upwards in world space — particularly useful after sampling from uneven terrain or landscapes.

This node is commonly used to introduce spatial randomness or controlled transformation in PCG graphs, forming an essential part of naturalistic procedural generation workflows.


## Parameter Space

OffsetMin / OffsetMax (FVector) — Defines a random translation range applied per point. The offset is sampled between the two vectors.
RotationMin / RotationMax (FRotator) — Defines a random rotation range (in degrees) applied per axis.
bAbsoluteRotation (bool) — If true, sets the rotation directly instead of adding to the existing rotation.
ScaleMin / ScaleMax (FVector) — Defines per-axis scale variation applied to each point.
bRecomputeSeed (bool) — When enabled, recalculates the seed for each transformed point to maintain deterministic randomization consistency.

## Connection Patterns

Input Pins:

Points (EPCGDataType::Point) — The incoming set of points to be transformed.

Typical input connections:
→ Surface Sampler (Out) — Applies random transform adjustments to surface-sampled points.
→ Scatter (Out) — Adds rotational or positional randomness to scattered points.
→ Merge Points (Out) — Adjusts combined point sets before placement or spawning.
→ Project Points (Out) — Applies final transform corrections after projection to surfaces.

Output Pins:

Points (EPCGDataType::Point) — Outputs the transformed set of points for downstream use.

Typical output connections:
→ Filter Points by Attribute (Points) — Filters transformed points based on new position, rotation, or scale attributes.
→ Spawn Actors / Instances (Points) — Instantiates meshes or gameplay actors using the transformed point data.
→ Attribute to Transform (Points) — Converts stored transform attributes back into live point transforms.
→ Merge Points (Points) — Combines multiple transformed outputs into a unified dataset.

Each connection allows the Transform Points node to serve as an intermediate stage for adjusting, refining, and preparing point data — a critical step in procedural placement, scattering, and environmental variation workflows.
